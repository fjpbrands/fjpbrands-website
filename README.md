# fjpbrands.com

Corporate Website für **FJP Brands GmbH** — präsentiert Unternehmen, Vision und das erste Produkt *Reality Check — Relationships*.

## Struktur

- `index.html` — Landing (Hero, Vision, Produkt, psychologische Modelle, Kontakt)
- `impressum.html` — Impressum gemäß § 5 TMG
- `privacy.html` — Datenschutzerklärung (DSGVO, deckt Website + App ab)
- `support.html` — Support-Seite (App Store Listing-URL)
- `style.css` — Stylesheet (Dark Mode, responsive)
- `assets/` — Grafiken

## Tech

- Statisches HTML/CSS — keine Framework-Abhängigkeiten, kein Build-Step
- Fonts via Google Fonts (`Instrument Serif`, `Inter`)
- Lokal testen: Doppelklick auf `index.html`

## Deployment

Wird über [Netlify](https://netlify.com) gehostet. Bei jedem Push auf `main` deployed Netlify automatisch.
